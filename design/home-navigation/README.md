# Homepage Life Path

The homepage keeps recording and recent memories first. Its former permanent text-link row is replaced by one collapsed Life Path; deliberate expansion reveals the product's recall surfaces as a continuous route and ends at Life Map.

## Evidence

- `before-desktop.png`, `before-mobile.png`: original permanent “More” link row.
- `after-desktop-closed.png`, `after-mobile-closed.png`: quiet default disclosure.
- `after-desktop-open.png`, `after-mobile-open.png`: expanded path.
- `after-narrow-open.png`: 320 px path behavior.

The screenshots use an empty temporary browser profile. No seed data is written to the user's application database.
